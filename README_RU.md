# Lucky 7 — 3D Игровой Автомат для Minecraft (Fabric 1.21.1)

[English Version](README.md) | **Русская версия**

**Lucky 7** — высококачественный, аутентичный мод на классический игровой автомат («однорукий бандит») в стиле ретро-казино для **Minecraft Java Edition 1.21.1** на базе **Fabric Loader** (Java 21).

---

## 🎰 Особенности мода

- **Полноразмерная 3D-модель (2 блока в высоту)**:
  - Модель автомата в полный рост игрока с золотыми молдингами, монетоприемником, светящимся табло (Marquee), витриной барабанов и физическим механическим рычагом.
  - Все поверхности монолитны, без просветов, отверстий и зазоров.
- **Физические 3D-барабаны в мире игры**:
  - Три независимых вращающихся барабана (18 символов на каждом) вращаются прямо за стеклом.
  - Плавное ускорение, поочередная остановка барабанов и механический щелчок фиксации символов на красной выигрышной линии.
- **Интерактивный GUI**:
  - **9 слотов для ставки** с динамическим расчетом стоимости депозита.
  - **Центральная панель шансов**: надписи категорий и проценты выигрыша находятся строго напротив соответствующих строк витрины призов.
  - **Автозакрытие окна при старте**: при нажатии кнопки «СТАРТ» с внесенной ставкой окно мгновенно закрывается, позволяя наблюдать вращение барабанов прямо в мире.
- **Сбалансированная витрина призов (27 слотов)**:
  - **Строка 0 (Джекпот)**: 16 незеритовых блоков, 32 незеритовых слитка, 64 алмазных блока, 16 древних обломков, кузнечные шаблоны улучшения, зачарованные золотые яблоки, 64 изумрудных и золотых блока.
  - **Строка 1 (Крупный выигрыш)**: по 64 штуки алмазов, изумрудов, золотых слитков, железных блоков, золотые яблоки, 64 пузырька опыта, зелья на 8 минут по 3 шт.
  - **Строка 2 (Обычный выигрыш)**: слитки железа, редстоун, кварц, лазурит, медные блоки (по 64 шт.), осколки аметиста (32 шт.), зелья на 8 минут по 1 шт.
  - **Гарантированная выдача полных стаков**: при победе игрок получает ровно тот полный стак, который видит в слоте витрины, без деления или урезания.
  - **Честный равномерный рандом**: каждый слот в категории имеет равный шанс выпадения.
- **Прием широкого спектра ставок**:
  - Руды, слитки, минеральные блоки: железо, золото, алмазы, незерит, изумруды (включая изумрудные блоки), медь, лазурит, редстоун, кварц, уголь, аметист.
  - Все инструменты и броня от железных до незеритовых.
  - Зачарованные золотые яблоки.
  - Редкие реликвии: элитры, тотемы бессмертия, звезда Незера, яйцо дракона, сердце моря, трезубец, булава, тяжелое ядро, ключи испытаний и маяки.
- **Секретная пасхалка**:
  - На барабанах присутствует символ `SKULL` (Череп). Если на выигрышной линии выпадут 3 черепа, игрок получает 3 HP (1.5 сердца) урона с анимацией дыма и звуком Визера. Пасхалка скрыта от статистики и инфо-меню.

## 🛠️ Каноничный рецепт крафта

Игровой автомат создается в обычном верстаке 3×3. Расположение предметов повторяет силуэт слот-машины:

```
[ Золотой слиток ] [ Лампа из редстоуна ] [ Золотой слиток ]  -> Золотая корона и светящееся табло
[ Золотой слиток ] [  Стеклянная панель  ] [     Рычаг      ]  -> Стекло барабанов и боковой рычаг
[ Железный блок  ] [   Блок редстоуна   ] [  Железный блок  ]  -> Массивный стальной корпус и питание
```

Результат: **1x Игровой автомат Lucky 7** (`lucky7:slot_machine`).

## ⚙️ Настройка конфигурации (`config/lucky7.json`)

Файл конфигурации создается автоматически при первом запуске:
- `winBase`: базовый шанс на любой выигрыш при минимальной ставке (по умолчанию 0.24 = 24%).
- `winMax`: максимальный шанс выигрыша при высоких ставках (до 85%).
- `jackpotBase` и `jackpotMax`: диапазон вероятности выпадения Джекпота (от 0.8% до 25%).
- `resourceValues`: настраиваемая стоимость каждого принимаемого предмета.

## 📦 Сборка и установка

- **Требования**:
  - Minecraft Java Edition 1.21.1
  - Fabric Loader >= 0.16.10
  - Fabric API >= 0.116.0
  - Java 21

- **Сборка из исходников**:
  ```bash
  ./gradlew build
  ```
  Готовый JAR-файл будет находиться в папке `build/libs/lucky7-1.0.0.jar`.
